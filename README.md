# היציקות שלי — אתר אישי לניהול עבודות יציקה בבטון

אתר סטטי (בלי שרת/דאטהבייס) בעברית ו-RTL, מותאם לנייד, שמרכז:

- **התבניות שלי** — תבניות מסווגות לפי קטגוריות, עם תמונה, מספר סידורי ותיאור.
  לחיצה על תמונה פותחת חלון עם נפח, כמות בטון וכמות מים נדרשים.
- **לוחות השראה** — צבעים (עם הצעת ערבוב), שילובי צבעים, אפקטים (שיש/טרצו)
  ודוגמאות שונות — כולם כגלריות תמונות.
- **מחשבון** — שלושה כלים:
  1. הזנת נפח תבנית → כמות בטון ומים.
  2. הזנת נפח חומר גלם (גבס) → 3 שילובי תבניות אקראיים לניצול הכמות.
  3. הזנת נפח חומר גלם + מספרי תבניות שכבר נבחרו → 5 הצעות לתבניות נוספות לניצול השארית.

## איך זה עובד מבחינה טכנית

האתר עצמו סטטי (בלי שרת/דאטהבייס) ורץ בחינם ב-GitHub Pages. תבניות
וקטגוריות נשמרות בקבצי `data/molds.json` ו-`data/categories.json`,
שנטענים בזמן אמת בכל טעינת דף — כך שכולם רואים תמיד את אותו מידע
עדכני. תוכן אחר (צבעים, שילובי צבעים, אפקטים, דוגמאות, הגדרות תערובת)
נמצא ב-`js/data.js`.

## איך מוסיפים תבנית חדשה — ותופיע מיד אצל כולם

בעמוד `admin.html` (יש קישור מהעמוד הראשי) יש שלושה טאבים:

### 1. "חיבור לגיטהאב" (הגדרה חד-פעמית)

כדי שהשמירה תיכתב ישירות לאתר החי, צריך טוקן גישה אישי של גיטהאב:

1. היכנסו לכתובת: `github.com/settings/personal-access-tokens/new`
2. תחת "Repository access" בחרו **Only select repositories** ובחרו
   רק את **hodaya-molds**.
3. תחת "Permissions" → "Repository permissions" שנו **Contents**
   ל-**Read and write**.
4. לחצו **Generate token**, העתיקו את הטוקן (מתחיל ב-`github_pat_`)
   והדביקו אותו בטאב "חיבור לגיטהאב" באתר.

הטוקן נשמר רק ב-localStorage של הדפדפן הזה, ונשלח רק ישירות מהדפדפן
ל-`api.github.com` — הוא לעולם לא עובר דרך שום שרת אחר. חשוב: טוקן כזה
מאפשר כתיבה לריפו הזה בלבד, אז יש לשמור עליו כמו על סיסמה ולא לשתף
אותו, ואפשר לבטל אותו בכל רגע בהגדרות גיטהאב (Settings → Developer
settings → Personal access tokens).

### 2. "תבנית חדשה"

1. בחרו סיווג קיים, או "+ סיווג חדש" והזינו שם.
2. מלאו מספר סידורי, תיאור, נפח כללי (מ״ל), ואפשר גם לצרף תמונה ישירות
   מהטלפון/מהמחשב.
3. לחצו "שמרו תבנית" — זה נכתב מיד לריפו בגיטהאב (כולל התמונה, אם
   צורפה). תוך כ-30–60 שניות (הזמן שגיטהאב פייג'ז לוקח לבנות מחדש את
   האתר) זה יופיע ב"התבניות שלי" אצל כולם, בלי צורך בשום דבר נוסף.

אפשר תמיד לשמור שוב תבנית עם אותו מספר סידורי כדי לעדכן אותה (למשל
להוסיף תמונה מאוחר יותר).

## איך מוסיפים תמונת השראה (שילוב צבעים / אפקט / דוגמה)

אלו עדיין לא כתובות ל-GitHub באופן אוטומטי (רק תבניות/קטגוריות): בטאב
**"תמונת השראה"** ב-`admin.html` בוחרים לאיזו גלריה, ממלאים מזהה
וכיתוב, ומקבלים קטע קוד מוכן + הוראות בדיוק לאן לשמור את התמונה
ולאן להדביק את הבלוק בקובץ `js/data.js` (`COLOR_COMBOS`,
`EFFECTS.marble`, `EFFECTS.terrazzo` או `PATTERNS`), ואז commit + push.
(אפשר להרחיב את זה בעתיד לאותה שיטה של כתיבה ישירה, בדיוק כמו תבניות.)

אפשר גם לערוך את `js/data.js` ישירות בלי `admin.html` — הפורמט של כל
מערך מוסבר בתחילת הקובץ. תבניות וקטגוריות נערכות ישירות ב-
`data/molds.json` ו-`data/categories.json` (גם ידנית וגם דרך `admin.html`).

## כיול חישוב הבטון והמים

בראש `js/data.js` יש אובייקט `MIX_SETTINGS`:

```js
const MIX_SETTINGS = {
  concreteDensityGPerMl: 1.9, // גרם אבקה לכל מ"ל נפח
  waterRatio: 0.18,           // יחס מים ממשקל האבקה
};
```

אלו ערכי ברירת מחדל בלבד (ניתן גם לשנות זמנית בעמוד המחשבון, בטאב
הראשון, תחת "הגדרות מתקדמות"). מומלץ לכייל אותם לפי המתכון האמיתי שבו
נעשה שימוש.

## הרצה מקומית

האתר לא דורש התקנות — פותחים את `index.html` ישירות בדפדפן, או מריצים
שרת סטטי פשוט מתוך התיקייה, למשל:

```bash
python3 -m http.server 8080
```

ואז נכנסים ל-`http://localhost:8080`.

## פרסום ב-GitHub Pages

1. Settings → Pages בריפו.
2. Source: "Deploy from a branch", ובחרו את הענף והתיקייה הראשית (`/`).
3. לאחר כמה דקות האתר יהיה זמין בכתובת שתופיע שם.

כל push לענף שנבחר יעדכן את האתר החי אוטומטית.
